# SENSING Camera Drivers For Intel IPU Devices

SENSING Camera Drivers are developed based on Intel IPU Devices.

Users of SENSING cameras can refer to these drivers to enable camera functionality on Intel IPU devices.

#### **Supported Intel IPU Devices:**

* **Panther Lake-H Customer Reference Board**

* **Arrow Lake-U/H Customer Reference Board**

* **Panther Lake-H DevKit**

  ![DevKit](Panther%20Lake-H%20DevKit/ROBINSON_BAY_INTEL_PTL_IPU7_CAMERA/pictures/device_dark_centered.png)


You can use DownGit to download specified camera driver package folder.

* Enter the path of the driver package folder to download and copy the link address in the browser's address bar
* Open the DownGit (https://minhaskamal.github.io/DownGit/#/home) webpage, and paste the link copied in the previous step into the address input box. Then click the Download button to start the download.
